Cómo se calcula

Una fila por solicitud; cada gráfico aísla una sola dimensión.

  1. Cada fila es una solicitud; target_good vale 1 si el crédito se devolvió.
  2. Los propósitos se leen de las columnas one-hot originales, no de una agrupación posterior.
  3. El tramo joven se deriva por exclusión: ni adulto (25-44) ni senior (45+).
  4. Se informa la tasa bruta por grupo; no hay modelo ni ajuste por otras variables.

Qué no dice este informe

Qué no se puede concluir con mil solicitudes.

  • Mil casos son pocos: un grupo de 50 solicitudes mueve la tasa varios puntos con un caso más.
  • Es una tasa bruta, sin controlar confusores: el propósito y la edad están correlacionados.
  • El dataset es de 1994 y en marcos alemanes; no describe el crédito actual.
  • No hay importe recuperado ni pérdida: solo se sabe si devolvió o no.
